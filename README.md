<H1>Sobre os projetos</H1>

<h2>Clique na tela:</h2>
- o desafio pedia para criar uma interface onde ao clicar aparecesse um circulo </br>
- deveria ter dois botoes: um para desfazer a acao e outro para refazer a acao </br>
<h3>- Logica utilizada</h3> -> usei a estrutura de dados em pilha para armazenar todos os itens adicionados na pilha de desfazer, e ao clicar em refazer, usando o principio LIFO, o ultimo item da pilha desfazer iria para a pilha refazer, podendo haver essa troca de items sem perder o historio de mudancas

<h2>Carrinho de compra:</h2>
- o desafio pedia para criar a lógica para um carrinho de compras com alguns requisitos: </br>
<ul>
  <li>Placeholder quando não houver itens no carrinho</li>
  <li>Inserção de novos produtos no carrinho</li>
  <li>Remoção de produtos</li>
  <li>Alteração na quantidade de itens</li>
  <li>Cálculo de preço total</li>
</ul>
<h3>- Logica utilizada</h3> <p>-> Usando o Zustand, uma biblioteca de gerenciamento de estado, centralizei as informações necessárias para componentes de qualquer nível terem fácil acesso, evitando o prop drilling.</p></br>
